# Comments for heyvaldemar.com

This repository holds the comment threads for [heyvaldemar.com](https://heyvaldemar.com). It is deliberately empty of code: [Giscus](https://giscus.app) stores every comment as a GitHub Discussion here, one discussion per article, and the site loads the widget under each post.

## Leaving a comment

Comment under the article you are reading on [heyvaldemar.com](https://heyvaldemar.com). Signing in with GitHub is required, because the comment becomes a reply in the matching discussion. You can also open [Discussions](../../discussions) directly and reply there; both views show the same thread.

## Why the repository looks empty

The article content lives in the site repository. This one exists only so Giscus has a place to write, and so the discussion permissions stay separate from the code. Nothing is built or deployed from here.

## Reporting a problem

For a broken comment widget or a moderation request, email **v@valdemar.ai** or open a discussion. Security reports for the site itself belong in the [security policy](https://heyvaldemar.com/security).
